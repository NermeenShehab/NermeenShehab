## About

Senior Frontend Developer & QA Lead with 4+ years of experience building production web applications with React, Next.js, and TypeScript. I currently lead frontend engineering and QA at **Dubai Link Group**, working across B2C and B2B travel platforms and internal operations tools for the MENA market, and manage a team of 4–5 engineers.

My work combines three areas:

- **Frontend engineering** — shared architecture, reusable component libraries, bilingual English/Arabic (RTL) interfaces, performance and accessibility.
- **Quality assurance** — test planning, manual and automated testing, API and regression testing, security testing, and release validation.
- **AI-powered developer tooling** — an MCP server on the Claude API that makes API testing accessible to technical and non-technical users.
